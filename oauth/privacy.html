개인정보처리방침

최종 수정일 2026년 9월 7일

1. 이 방침의 대상

이 방침은 kimjaewoook automation에 적용됩니다. 이 도구는 제작자 본인의 개인 업무 자동화를 위해 만들어졌으며 제작자 한 명만 사용합니다.

2. 접근하는 정보

이 도구는 사용자가 직접 로그인해 동의한 범위에서 아래 구글 계정 정보에 접근합니다.

  • 구글 스프레드시트 읽기와 쓰기
  • 구글 드라이브 파일 읽기와 쓰기
  • 구글 앱스 스크립트 프로젝트 생성과 배포

접근 대상은 사용자 본인의 파일로 한정됩니다.

3. 수집하거나 저장하지 않는 것

  • 개인정보를 별도로 수집하지 않습니다
  • 서버에 데이터를 전송하거나 보관하지 않습니다. 이 도구에는 서버가 없습니다
  • 구글에서 받은 인증 토큰은 사용자 본인의 컴퓨터에만 저장됩니다
  • 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다
  • 광고와 분석 목적으로 사용하지 않습니다

4. 정보를 쓰는 목적

사용자가 지시한 작업을 수행하는 데에만 씁니다. 표 정리, 서식 적용, 자료 수집과 기록이 그 예입니다. 그 밖의 목적으로는 쓰지 않습니다.

5. 보관과 삭제

인증 토큰은 사용자 컴퓨터의 로컬 파일로만 존재합니다. 해당 파일을 지우면 접근 권한이 사라집니다. 구글 계정 설정에서 언제든 이 앱의 접근 권한을 철회할 수 있습니다.

구글 계정 권한 관리 페이지

6. 구글 API 서비스 사용자 데이터 정책

이 도구의 구글 API 사용은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용 요건이 포함됩니다.

7. 변경

이 방침이 바뀌면 이 페이지를 고치고 위의 최종 수정일을 갱신합니다.
