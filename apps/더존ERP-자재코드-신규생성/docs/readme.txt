[ 더존ERP-자재코드-신규생성 ]
더존ERP 품목등록(BAS0110) 자재코드 신규생성 자동화 매크로

■ 개요
  마스터 구글시트 '발주관리_단가테이블'에서 미등록 품목을 자동 조회한 뒤,
  더존ERP 품목등록 화면에 자동으로 키인하는 매크로 프로그램입니다.

■ 필터 조건
  - 자재코드(구매) 맨 앞 숫자가 2, 3, 4, 5로 시작
  - 유효여부 = O
  - 더존입력완료 = 공백

■ 키인 시퀀스 (1건당)
  1. 자재코드(구매) 붙여넣기 → 엔터
  2. 자재명 붙여넣기 → 엔터
  3. 공급업체명(정식) 붙여넣기 → 엔터
  4. 숫자 0 → 엔터
  5. 숫자 0 → 엔터
  6. "EA" 입력 → 엔터 x 31회
  → 다음 품목으로 반복

■ 사용 라이브러리
  - pynput (키보드 제어)
  - gspread (구글 시트 API)
  - python-dotenv (환경변수)

■ 실행 방법
  - 더존ERP-자재코드-신규생성.command 더블클릭
  - 또는 터미널에서 python3 더존ERP-자재코드-신규생성.py

■ 종료 방법
  - ESC 키를 누르면 즉시 매크로 중단
