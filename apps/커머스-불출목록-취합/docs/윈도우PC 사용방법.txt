  3단계. 환경변수 파일(.env) 만들기  (딱 1번만 하면 됩니다)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  봇이 각 사이트에 자동 로그인하려면, 여러분의 계정 정보가
  담긴 ".env" 파일이 필요합니다. 아래 순서대로 만들어 주세요.


  ── [사전 준비] 확장자 보이게 설정하기 ──

  윈도우는 기본적으로 파일 확장자(.txt, .xlsx 등)를 숨깁니다.
  .env 파일을 정확히 만들려면 확장자를 보이게 바꿔야 합니다.

    ① 파일 탐색기 상단 메뉴에서 [보기] 탭을 클릭하세요.
    ② [파일 이름 확장명] 항목에 체크(✅)하세요.
       → 이제 파일명 뒤에 .txt 같은 확장자가 보입니다.

  ※ Windows 11: 상단 메뉴 [보기] → [표시] → [파일 이름 확장명]


  ── .env 파일 만들기 ──

  ① "py_commerce-item" 폴더의 빈 공간에서 마우스 우클릭합니다.

  ②  [새로 만들기] → [텍스트 문서] 를 클릭합니다.
     → "새 텍스트 문서.txt" 가 생성됩니다.

  ③ 파일 이름을 클릭해서, 이름과 확장자(.txt)를 모두 지우고
     정확히 아래처럼 입력합니다:

        .env

     🚨 주의: "env.txt" 가 아니라 ".env" 입니다!
        앞에 점(.)이 꼭 있어야 합니다.
        확장자까지 전부 지우고 ".env" 로 바꿔야 합니다.

     "확장명을 변경하면..." 경고창이 뜨면 [예] 를 누르세요.

  ④ 생성된 .env 파일을 우클릭 → [연결 프로그램] → [메모장] 으로 엽니다.

  ⑤ 메모장에 아래 내용을 복사·붙여넣기 한 뒤,
     "여기에입력" 부분을 본인의 실제 계정 정보로 교체하세요.

  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │  METABASE_URL=여기에메타베이스주소입력                   │
  │  LAUNDRYGO_ORDER_URL=여기에런드리고주문관리주소입력      │
  │  LAUNDRYGO_ORDER_ID=여기에런드리고아이디입력             │
  │  LAUNDRYGO_ORDER_PW=여기에런드리고비밀번호입력           │
  │  WMS_EZSTORAGE_URL=여기에WMS주소입력                    │
  │  WMS_EZSTORAGE_ID=여기에WMS아이디입력                   │
  │  WMS_EZSTORAGE_PW=여기에WMS비밀번호입력                 │
  │                                                         │
  └─────────────────────────────────────────────────────────┘

  ★ 입력 예시 (실제 값은 다릅니다):
  ─────────────────────────────────────────────────
    METABASE_URL=https://metabase.example.com
    LAUNDRYGO_ORDER_URL=https://order.laundrygo.com
    LAUNDRYGO_ORDER_ID=hong@company.com
    LAUNDRYGO_ORDER_PW=mypassword123
    WMS_EZSTORAGE_URL=https://wms.ezstorage.co.kr
    WMS_EZSTORAGE_ID=hong
    WMS_EZSTORAGE_PW=wmspass456
  ─────────────────────────────────────────────────

  🚨 주의사항:
     - = 앞뒤에 공백(띄어쓰기)을 넣지 마세요!
     - 값에 따옴표("")를 감싸지 마세요!
     - 각 항목은 한 줄에 하나씩 적어야 합니다.
     - 본인의 계정이 뭔지 모르겠다면 팀장에게 문의하세요.

  ⑥ 메모장에서 Ctrl + S 로 저장하고, 메모장을 닫습니다.

  ✅ 환경변수 파일 생성 완료!

  ③ 큰 Chrome 창에서 아래 3개 사이트에 직접 수동 로그인합니다:

     ★ 로그인할 사이트 목록:
        1) Metabase — Google 계정으로 로그인
        2) 런드리고 주문관리 — 아이디/비밀번호 입력
        3) ezstorage (WMS) — 아이디/비밀번호 입력

  ④ 3개 사이트 모두 로그인을 마쳤으면,
     작은 창(Playwright Inspector)을 봐 주세요.

     ┌───────────────────────────────────────────┐
     │  Playwright Inspector                      │
     │                                            │
     │   ▶ Resume (F8)    ← 이 버튼을 클릭!      │
     │                                            │
     └───────────────────────────────────────────┘

  ⑤ 봇이 자동으로 데이터를 수집하고 가공합니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ─────────────────────────────────────────────────
  Q. 까만 창에 "Python이 설치되어 있지 않습니다" 라고 나와요.
  ─────────────────────────────────────────────────
  A. 파이썬 설치 시 "Add Python to PATH" 체크를 안 하신 겁니다.
     → 파이썬을 삭제 후 다시 설치하면서 반드시 체크해 주세요.


  ─────────────────────────────────────────────────
  Q. "환경변수 'xxx' 누락" 오류가 나와요.
  ─────────────────────────────────────────────────
  A. .env 파일에 빠진 항목이 있거나, 오타가 있습니다.
     → .env 파일을 메모장으로 열어서 7개 항목이 모두 있는지,
       = 앞뒤에 공백이 없는지 확인해 주세요.


  ─────────────────────────────────────────────────
  Q. .env 파일이 아니라 "env" 라는 폴더가 생겼어요.
  ─────────────────────────────────────────────────
  A. 확장자가 숨겨져 있어서 ".env.txt"로 만든 것일 수 있습니다.
     → 1단계 [사전 준비]의 확장자 보이기 설정을 먼저 하세요.


  ─────────────────────────────────────────────────
  Q. 로그인이 풀려서 봇이 에러를 내요.
  ─────────────────────────────────────────────────
  A. 오래되면 세션(쿠키)이 만료될 수 있습니다.
     아래 방법으로 세션을 다시 구워 주세요:

     ① py_commerce-item 폴더 안의 .playwright_profile 폴더를
        통째로 삭제합니다.  (숨겨진 폴더일 수 있으니 확인)
     ② run.bat 을 다시 더블클릭하면 4단계(세션 굽기)가
        자동으로 진행됩니다.


  ─────────────────────────────────────────────────
  Q. output 폴더에 파일이 하나도 없어요.
  ─────────────────────────────────────────────────
  A. 봇 실행 중 에러가 발생한 것일 수 있습니다.
     → 까만 창에 빨간 글씨나 "❌" 표시가 있는지 확인하고,
       해당 내용을 스크린샷 찍어서 개발 담당자에게 보내주세요.


  ─────────────────────────────────────────────────
  Q. 봇 실행 중에 PC를 꺼도 되나요?
  ─────────────────────────────────────────────────
  A. 안 됩니다. 봇이 "전체 작업 완료" 메시지를 출력할 때까지
     PC를 켜둔 채로 기다려 주세요. (보통 3~10분 소요)
