[ 더존ERP-자재코드-미사용처리 ]
ERP 자재코드 미사용처리 자동화 매크로

■ 개요
  더존ERP 품목등록(BAS0110) 화면에서 자재코드를 미사용 처리할 때,
  반복적인 키보드 입력 작업을 자동으로 수행하는 매크로 프로그램입니다.

■ 주요 기능
  - Tab, Enter, 방향키(↑↓) 등 정해진 키 시퀀스를 무한 반복 자동 입력
  - ESC 키를 누르면 즉시 매크로 종료
  - 3초 대기 후 매크로가 시작되어 ERP 화면에 커서를 미리 위치시킬 수 있음

■ 사용 라이브러리
  - pynput (키보드 입력 제어 및 감지)

■ 실행 방법
  - 더존ERP-자재코드-미사용처리.command 더블클릭
  - 또는 scripts/실행하기.command 더블클릭
