💻 초보자용 가이드

파이썬 자동화 프로그램
초기 세팅 및 실행 매뉴얼

터미널이나 파이썬이 처음이신 분들을 위해 쉽게 작성되었습니다.
최초 1회만 아래 순서대로 천천히 따라와 주세요!

1단계: 터미널(Terminal) 창 열기

명령어를 입력할 수 있는 까만 창을 여는 단계입니다.

  1. 맥북 화면 오른쪽 위의 돋보기 아이콘(Spotlight)을 클릭하거나, 키보드에서 command ⌘ + 스페이스바 를 누릅니다.
  2. 검색창에 터미널 또는 Terminal이라고 치고 엔터를 누릅니다.
  3. 텍스트가 떠 있는 조그만 창이 열리면 성공입니다! (여기에 앞으로 명령어를 입력할 겁니다.)

2단계: 파이썬(Python) 설치하기

코드를 실행하기 위한 기본 엔진을 설치합니다.

  1. 인터넷 창을 열고 파이썬 공식 홈페이지(다운로드)에 접속합니다.
  2. 가장 최신 버전의 파이썬 설치 파일(macOS 64-bit universal2 installer)을 클릭해 다운로드합니다.
  3. 다운로드된 파일을 더블클릭해서 일반적인 프로그램 설치하듯 '계속'을 눌러 설치를 완료해 줍니다.
  4. 잘 설치되었는지 확인하려면, 열어둔 터미널 창에 아래 명령어를 복사해서 붙여넣고 엔터를 치세요.
    python3 --version
    (숫자로 된 파이썬 버전이 출력되면 완벽하게 설치된 것입니다!)

3단계: 환경변수 및 보안 키 설정하기 (.env)

프로그램이 구글 시트나 메일, 슬랙 등에 접근하려면 '비밀번호' 역할을 하는 환경변수 파일이 필요합니다.

  1. 공유받으신 ai 폴더를 맥북의 바탕화면(Desktop)에 복사(저장)해 주세요.
  2. 맥북에서 바탕화면에 있는 ai 폴더를 엽니다.
  3. 이 ai 폴더 바로 안에 .env 라는 이름의 텍스트 파일을 새로 만들어야 합니다.
    💡 맥북 숨김 파일 보기
    맥북에서는 점(.)으로 시작하는 파일이 숨김 처리되어 안 보일 수 있습니다. 폴더 창을 열고 command ⌘ + shift ⇧ + . 을 누르시면 숨김 파일이 보입니다.
  4. 빈 텍스트 파일(텍스트 편집기 사용)을 열고, 별도로 전달받으신 보안 키(설정값) 내용을 그대로 복사해서 붙여넣습니다.
  5. 파일의 저장 이름을 .env 로 설정하고 저장해 줍니다. (확장자 .txt가 붙지 않도록 주의해 주세요.)

4단계: 작업 폴더로 이동 후 필수 부품 설치하기

프로그램이 돌아가는 데 필요한 부가 기능(라이브러리)들을 한 번에 설치합니다.

  1. 다시 터미널 창으로 돌아옵니다.
  2. 아래 명령어를 복사해서 붙여넣고 엔터를 치세요. (터미널의 위치를 ai/laundrygo/apps 폴더 안으로 이동시키는 명령어입니다.)
    cd ~/Desktop/ai/laundrygo/apps
  3. 폴더 이동이 끝났다면, 아래 명령어를 복사해서 붙여넣고 엔터를 치세요.
    pip3 install -r requirements.txt
  4. 터미널 화면에 무언가 촤르륵 올라가면서 설치가 진행됩니다. 설치가 완료되어 다시 입력창이 뜰 때까지 잠시 기다려주세요.

5단계: 프로그램 실행하기! 🎉

모든 준비가 끝났습니다! 이제 프로그램을 돌려보겠습니다.

  1. 터미널 창에 실행하시려는 파이썬 파일 이름을 적고 엔터를 칩니다.
    (예를 들어 실행할 파일이 main.py 라면 아래처럼 입력합니다.)
    python3 main.py
  2. 이제 프로그램이 알아서 열심히 일을 시작할 것입니다!

💡 다음번에 다시 실행하실 때는?

1~4단계(초기 세팅)는 최초 한 번만 하시면 되므로 두 번 다시 하실 필요가 없습니다!
다음번부터는 딱 두 가지만 하시면 됩니다.

  1. 터미널 열고 폴더 이동하기:
    cd ~/Desktop/ai/laundrygo/apps 치고 엔터!
  2. 프로그램 실행하기:
    python3 실행할파일이름.py 치고 엔터!
