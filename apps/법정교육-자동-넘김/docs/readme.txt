[ py_legal-edu ]
법정의무교육 자동 수강 프로그램

■ 개요
  한국안전교육협회(esafetykorea) 법정의무교육 사이트에서
  강의 플레이어의 '다음' 버튼 클릭과 퀴즈 응답을 자동으로 처리하는 프로그램입니다.

■ 주요 기능
  - Playwright 기반 브라우저 자동화 (자동화 탐지 우회 적용)
  - 사용자가 수동으로 로그인 → 강의 시작 후, 팝업 플레이어를 자동 감지
  - '다음' 버튼 활성화 시 자동 클릭
  - 알려진 퀴즈(OX 문제) 자동 정답 선택 및 제출
  - 영상 종료 감지 → 자동 다음 페이지 이동
  - 5초 간격으로 상태 모니터링 (무한 루프)

■ 사용 라이브러리
  - playwright (브라우저 자동화)

■ 실행 방법
  - auto_education.command 또는 run_edu.command 더블클릭
  - 브라우저가 열리면 직접 로그인 후 강의를 시작하면 자동 진행됨
