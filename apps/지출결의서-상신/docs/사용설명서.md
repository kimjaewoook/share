# 📋 지출결의서 자동 상신 봇 — 사용설명서

> 코딩 경험이 없는 실무자도 이 문서만 따라하면 바로 사용할 수 있습니다.

---

## 📁 폴더 구성

```
py_지출결의서/
├── main.py            ← 봇 핵심 코드 (수정 금지)
├── requirements.txt   ← 필수 라이브러리 목록
├── credentials.json   ← 구글 API 인증 키 (별도 전달)
├── 초기설정.bat        ← ⭐ 최초 1회 실행
├── 봇구동.bat          ← ⭐ 매일 실행
└── 사용설명서.md       ← 지금 보고 있는 문서
```

---

## 🔧 최초 1회: 환경 설정

### STEP 1. 파이썬 설치

1. [python.org/downloads](https://www.python.org/downloads/) 에서 최신 버전 다운로드
2. 설치 프로그램 실행

> ⚠️ **반드시 아래 체크박스를 선택하세요!**
>
> ![Add Python to PATH](https://docs.python.org/3/_images/win_installer.png)
>
> 설치 화면 하단의 **`✅ Add Python to PATH`** 를 반드시 체크한 뒤 **Install Now** 클릭하세요.
> 이걸 빠뜨리면 봇이 작동하지 않습니다.

3. 설치 완료 후 PC를 **재부팅**합니다.

---

### STEP 2. 환경변수 파일(`.env`) 확인

봇 폴더의 **상위 폴더**에 `.env` 파일이 있어야 합니다.  
파일 안에 아래 4개 값이 모두 채워져 있는지 확인하세요.

```
LAUNDRYGO_GW_URL=https://회사그룹웨어주소
LAUNDRYGO_GW_ID=그룹웨어아이디
LAUNDRYGO_GW_PW=그룹웨어비밀번호
END_OF_MONTH_SHEET_URL=구글시트링크
```

> 💡 `.env` 파일이 보이지 않는다면, 윈도우 탐색기 상단 → **보기** → **"숨긴 항목"** 을 체크하세요.

---

### STEP 3. 구글 인증 파일 배치

전달받은 `credentials.json` 파일을 `py_지출결의서` 폴더 안에 넣어주세요.

---

### STEP 4. 초기설정 실행

1. `초기설정.bat` 파일을 **더블클릭**합니다.
2. 검은 터미널 창이 열리며 자동으로 설치가 진행됩니다.
3. 아래 메시지가 나타나면 성공입니다:

```
✅ 모든 초기 설정이 완료되었습니다!
```

4. 아무 키나 눌러 창을 닫습니다.

> ⏱️ 첫 실행 시 약 2~5분 정도 소요됩니다. 인터넷이 반드시 연결되어 있어야 합니다.

---

### STEP 5. 구글 시트 최초 인증

1. `봇구동.bat`을 **처음** 실행하면 브라우저가 열리며 구글 로그인 화면이 뜹니다.
2. 구글 시트 접근 권한이 있는 계정으로 로그인 → **허용**을 눌러주세요.
3. 인증이 완료되면 `token.json` 파일이 자동 생성됩니다.
4. **이후부터는 이 과정이 생략**되므로 매번 할 필요 없습니다.

---

## 🚀 매일 사용법

### 1단계: 구글 시트 데이터 입력

그룹웨어에 올릴 지출결의서 내용을 구글 시트에 입력합니다.

### 2단계: 봇 실행

`봇구동.bat` 파일을 **더블클릭**합니다.

### 3단계: 자동 처리 확인

1. 터미널에 데이터 미리보기가 표시됩니다.
2. 3초 후 브라우저가 자동으로 열리며 그룹웨어에 데이터를 입력합니다.
3. 모든 입력이 끝나면 아래 메시지가 표시됩니다:

```
✅ 모든 봇 작업이 완료되었습니다! 브라우저 창에서 내용을 확인하고 직접 상신해 주세요.
```

4. **브라우저 화면에서 입력된 내용을 꼭 확인**한 뒤, 직접 `상신` 버튼을 눌러주세요.
5. 확인이 끝나면 터미널에서 `Enter` 키를 눌러 종료합니다.

## ❗ 문제 해결 (FAQ)

### Q1. `'python'은(는) 내부 또는 외부 명령...이 아닙니다` 에러

**원인**: 파이썬 설치 시 `Add Python to PATH` 체크를 안 한 경우  
**해결**:
1. 파이썬을 제거(프로그램 추가/제거)한 뒤 재설치
2. 설치 시 반드시 **`Add Python to PATH`** 체크
3. PC 재부팅

---

### Q2. `초기설정.bat` 실행 시 빨간 에러 메시지

**원인**: 인터넷 미연결 또는 방화벽 차단  
**해결**:
1. 인터넷 연결 상태 확인
2. 사내 VPN이 켜져 있다면 끄고 재시도
3. 그래도 안 되면 IT팀에 방화벽 해제 요청 (`pypi.org`, `playwright.azureedge.net` 허용)

---

### Q3. 봇 실행 중 브라우저가 멈추거나 에러 팝업

**원인**: 그룹웨어 페이지 로딩 지연 또는 구조 변경  
**해결**:
1. `output/` 또는 `archive/` 폴더에 에러 스크린샷(`error_snap.png`)이 저장되어 있으니 확인
2. 봇을 닫고 다시 `봇구동.bat` 실행
3. 반복되면 담당 개발자에게 에러 스크린샷 파일 전달

---

### Q4. `❌ 환경 변수 세팅 에러` 메시지

**원인**: `.env` 파일이 없거나 필수 값이 비어 있음  
**해결**: 상위 폴더의 `.env` 파일을 열어 4개 항목이 모두 채워져 있는지 확인

---

### Q5. 구글 시트 인증 에러 (`credentials.json` 관련)

**원인**: 인증 파일 누락 또는 만료  
**해결**:
1. `credentials.json` 파일이 폴더 안에 있는지 확인
2. `token.json` 파일을 삭제한 뒤 `봇구동.bat` 재실행 → 구글 재인증 진행
